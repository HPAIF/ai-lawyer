# Law cards

One file per act the company relies on, created by the `add-law` skill from the plugin's `templates/law-card.md`.
File name: `<area>-<short-name>.md`, e.g. `tax-tax-code.md`, `data-personal-data-law.md`.

A law card is a **verified snapshot**, not proof that the law is still current.
`verify-law` must re-check the official source every time the card is used in advice,
and append a row to the card's verification log.

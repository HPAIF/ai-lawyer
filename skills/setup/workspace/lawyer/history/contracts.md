# Contract register

> Every contract the company signs, negotiates, renews or terminates. Written by `log-job`
> and `contract-review`. Never delete a row; change status and add a dated event.
> Status: draft / negotiating / signed / active / expired / terminated / disputed.
> Other members' records: use their prefix (e.g. `accountant:C-0002`).

| ID | Counterparty | Type | Status | Signed | Starts | Ends / renewal | Value | Key terms & risks | File location | Review memo | Other member ref |
|---|---|---|---|---|---|---|---|---|---|---|---|

## Event log
> `C-xxxx · YYYY-MM-DD · event` — e.g. "C-0001 · 2027-02-01 · signed by both parties".

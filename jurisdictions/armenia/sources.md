# Official source registry — Armenia

> Where the AI lawyer is allowed to take the law from. Tier 1 = authoritative text; Tier 2 =
> official but explanatory; Tier 3 = leads only (never the basis of a conclusion).
> "Reachable" = answered an automated request on the date shown. If a site stops answering,
> note it here and use the fallback.

## Tier 3 — leads only

Law-firm guides (Chambers, Lexology/Panoramic, local firms), news (Armenpress, ARKA, news.am,
EVN Report), consultancies, AI summaries. Use them to learn *what to look up*, then verify in
Tier 1. Record the lead URL in the research memo, marked "lead".

## Rules for using sources
1. Find the act in ARLIS → open the Armenian edition → note status, latest amendment, any
   amendment adopted but **not yet in force**, and transitional provisions.
2. If you quote an English/Russian translation, state its edition date and say if the
   Armenian edition is newer.
3. For anything forward-looking, also search parliament.am and e-draft.am for pending changes.
4. For practice/interpretation, search datalex.am (Court of Cassation first) and concourt.am.
5. For regulator positions (tax, data), check the regulator's clarifications (Tier 2).
